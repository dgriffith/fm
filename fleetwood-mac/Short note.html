Short note — expansion plan

This is a short planning note. It records my intent to expand the Fleetwood Mac project beyond the current thematic notes by pulling in external sources gathered through web search and quantitative data tables downloaded from industry sources.

Right now the project’s notes are essentially analytical prose — narrative arcs and interpretation. The aim here is to give that analysis an evidentiary and quantitative backbone, so claims about commercial success, lineup changes, and legacy can be grounded in citable sources and actual figures rather than received wisdom.

What I want to add

  • Secondary sources via web search — interviews, retrospectives, biographies, and critical reappraisals to cite in the existing notes. Priority targets are the notes that currently make evaluative claims without references, e.g. commercial-success-and-the-album-sales-question, fleetwood-macs-influence-and-critical-reassessment, and peter-green-genius-breakdown-and-reassessment.
  • Industry data tables — structured, downloadable datasets I can drop into notes as markdown tables and query with sql, or load in a python cell for charts. Candidates:
    • Album and single chart positions (Billboard, UK Official Charts).
    • Certified sales / streaming figures (RIAA, BPI, IFPI).
    • Discography metadata — release dates, labels, personnel per album — useful for the lineup-instability-as-structural-feature and the-songwriting-economy-of-the-classic-lineup angles.

How it plugs into the existing notes

The download-and-analyze work should feed the notes that are inherently quantitative:

  • commercial-success-and-the-album-sales-question — the natural home for a sales/certification table.
  • the-songwriting-economy-of-the-classic-lineup — songwriting credits per member per album lend themselves to a table + chart.
  • lineup-instability-as-structural-feature — a timeline of personnel by era.
